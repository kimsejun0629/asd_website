# 편집 모드 (`dev/edit.html`)

게시하지 않는 개발 페이지. `web/` 쪽을 iframe으로 띄워 요소를 끌어 옮기고 크기를 바꾼다. `web/` 파일은 건드리지 않는다.

- 열기: `http://[::1]:8768/dev/edit.html` (주소에 `?p=aero&w=900`을 붙여 쪽 · 폭 지정 가능)
- 바꾼 값은 iframe 안 요소에 인라인(`!important`)으로만 덧씌운다: `translate` · `width`/`height`(+`max-*: none`) · `scale`.
- 저장: 브라우저 localStorage(`kaedit:<쪽>`), 폭 구간(≥901 · 601–900 · ≤600)마다 따로. 다른 브라우저 · 시크릿 창에서는 안 보인다.
- 선택자는 가장 가까운 고유 `id`부터의 `nth-of-type` 경로. 구조가 바뀌면 "못 찾음"으로 표시된다.

## 반영 절차

1. 편집 후 **모든 쪽 JSON 받기**(또는 **이 쪽 CSS 보기** → 복사)를 Claude에게 전달한다.
2. Claude는 경로 선택자를 실제 클래스로, px 값을 기존 토큰 · 중단점 · 상대 단위로 옮겨 `css/<쪽>.css`에 적는다(내보낸 CSS를 그대로 붙이지 않는다). 국문 · 영문 짝을 함께 확인한다.
3. 반영 뒤 편집 모드에서 그 쪽을 **이 쪽 모두 지우기** — 남겨 두면 인라인 값이 새 CSS 위에 겹친다.

## 한계

- 왼쪽 · 위 손잡이는 반대편 가장자리를 고정하려고 `translate`를 함께 바꾼다. 가운데 정렬 요소는 양쪽으로 커져 어긋나 보일 수 있다.
- 배율 방식은 `transform-origin`(보통 가운데) 기준. 인라인 요소는 자동으로 배율 방식.
- 사이트 JS가 같은 속성을 인라인으로 쓰는 요소는 편집값이 이기므로 움직임이 달라질 수 있다(반영할 때 확인).
- 3D 캔버스는 CSS 크기만 바뀐다(해상도 · 카메라는 그대로).
